# Mobius —— 会自我进化的智能体操作系统

> **Mobius（莫比乌斯）** 是一个**自我进化的多智能体操作系统**（Self-Evolving Multi-Agent Operation System）。
> 你不需要事事亲力亲为：把目标说清楚，剩下的交给智能体团队——它们能开发任意项目、任意功能，
> 也能回过头来改造 Mobius 自身，让系统持续迭代。

本篇是文档站的入口。文档按「**先跑起来 → 再上能力 → 最后进阶**」的顺序组织，跟着走一遍即可上手。
