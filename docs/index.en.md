# Mobius — A Self-Evolving Agent Operating System

> **Mobius** is a **self-evolving multi-agent operating system**. You don't have to do everything
> yourself: describe the goal, and the agent team takes over — building any project or feature,
> and even reworking Mobius itself so the system keeps evolving.

This page is the entry point of the documentation. The guide is organized as
**get running → level up → go deep**. Follow it once and you are up to speed.
