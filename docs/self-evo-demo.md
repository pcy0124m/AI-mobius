# 简单自进化示例

> **自我进化**是 Mobius 最核心的能力：系统能够修改**它自己**。
> 本节用一个最小示例，演示「提出需求 → 受控改动 → 验证 → 重新部署」的完整闭环。

## 为什么叫「自我进化」

Mobius 把「改造自身」也当成一个普通项目来管理——不是让智能体随意改线上系统，而是在**自迭代项目**里创建**受控任务**，走和普通开发任务一样的流程：拆解、编码、验证、交付。改动通过后重新部署，新能力对所有人生效。

这也意味着：你不必等官方发版。需要什么能力，直接提。

## 示例流程（概述）

1. **打开小莫** —— 也就是整个 Agent 操作系统的控制中枢，见 [万能捷径：小莫助理](tutorial/13_xiaomo_control_hub.md)。
2. **用一句话描述目标** —— 例如「给系统加一个 XX 能力」或「修掉 YY 这个 Bug」。
3. **小莫创建受控任务** —— 它会在自迭代项目里开出任务单，拆解成若干可执行的子任务。
4. **智能体动手改动** —— 编码、在环境中验证、提交改动。
5. **重新部署生效** —— 系统更新完成后，新能力即可使用。
